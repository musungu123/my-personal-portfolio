# Joyce | Personal Portfolio

A responsive one-page portfolio built with HTML, CSS and Tailwind CSS (via CDN). No build step or JavaScript framework is needed.

## Sections

- **Hero:** introduction and links to projects and contact
- **About:** short bio, skills and experience
- **Projects:** Pictures, African Kismat Expeditions and Akan Name Generator, each with live and source links
- **Contact:** email, social links and a contact form

## Files

```
├── index.html   # page content and Tailwind classes
├── style.css    # fonts, colours and the hero animation
└── README.md
```

## Run it
Fork the repository and then clone it.
Navigate into that repository and open index.html.
Go live to see the website.

An internet connection is needed for Tailwind and Google Fonts.

## Customise

- Edit the text, projects and links in `index.html`.
- Replace the hero photo with your own image.
- Set your Formspree URL in the form's `action` so the contact form works.
-git add and push your work to github.

## Deploy

Push to GitHub, then go to **Settings > Pages** and publish from the `main` branch.

## Built with

HTML5, CSS3 and Tailwind CSS.
